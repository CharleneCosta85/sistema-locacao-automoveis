# Sistema de Locação de Automóveis — Frontend

Protótipo acadêmico em React + Vite baseado nos requisitos e nos diagramas UML do projeto.

## Telas
- Login (simulado)
- Consulta de veículos
- Filtro por categoria/modelo
- Nova reserva
- Minhas reservas
- Dashboard do funcionário
- Clientes
- Pagamentos
- Meus dados

## Executar
1. Instale o Node.js.
2. Abra o PowerShell nesta pasta.
3. Execute: `npm install`
4. Execute: `npm run dev`
5. Abra o endereço informado pelo Vite.

## Importante
Este é um frontend/protótipo. Não possui backend real, PostgreSQL, Redis, JWT ou gateway de pagamento. Essas partes estão representadas na arquitetura e poderão ser conectadas posteriormente.
